# Themis Skyblock Beta 1.7.3
Skyblock plugin for Beta 1.7.3!

# Commands
- /sb create - Creates island
- /sb visit [nickname] - Visit island of player
- /sb home - Go back to your island
- /sb add [nickname] - Add friend to island
- /sb remove [nickname] - Remove friend from island
- /sb challenge - Exchange 64 Cobblestone to 5 Iron Ignots
